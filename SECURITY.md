# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability in this project, please report it via our 
official channels rather than opening a public issue.

* **Vulnerability Disclosure:** Please report issues to security@backblaze.com.
* **Scope Note:** Please note that while we welcome all security reports, this specific 
    repository is currently **not eligible for monetary rewards** under our bug bounty program.

We appreciate your help in keeping our users safe!
