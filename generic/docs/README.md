# Generic (Non-RMM) Scripts

This folder contains platform-agnostic bash scripts for controlling Backblaze Desktop Client using `bzcli`.

Use these scripts when you are not using a supported RMM/MDM platform (Jamf, Kandji, Addigy, JumpCloud), or as a reference implementation to adapt to other tools.

## Requirements
- macOS with Backblaze Desktop Client installed
- `bzcli` available at:
  `/Applications/Backblaze.app/Contents/MacOS/bzcli`

See `generic/docs/actions.md`.
