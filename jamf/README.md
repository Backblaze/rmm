# Backblaze for Jamf Pro

This directory contains the **Jamf Pro** implementation for deploying and managing Backblaze Computer Backup on macOS.

It includes:

- Jamf-focused documentation
- Installation scripts
- Operational action scripts
- Reporting and inventory extensions
- Configuration profiles used during deployment

## Directory structure

```text
jamf/
├── README.md
├── docs/
├── profiles/
└── scripts/
```

## What this folder is for

The `jamf/` folder is the Jamf Pro baseline for Backblaze Desktop deployments. It is intended to support:

- Standard Jamf Pro installations
- Decentralized enterprise deployments
- Operational actions through Jamf policies
- Inventory, reporting, and compliance visibility

## Key documentation

Start with:

- `jamf/docs/README.md`
- `jamf/docs/install-backblaze-client-silently-with-jamf-pro-mac.md`
- `jamf/docs/how-to-install-the-backblaze-client-silently-with-jamf-pro-mac.md`

## Notes

- Scripts in this folder are written for Jamf Pro workflows on macOS
- Profiles in `jamf/profiles/` can be uploaded directly into Jamf Pro
- Reporting and inventory scripts are intended for Extension Attributes and operational monitoring
